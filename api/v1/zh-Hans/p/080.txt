Motion Prompt #080 · 落地页与网页效果

效果含义：重点文字下方逐渐画出色带
示例表现：文案滚入视口时，黄色荧光笔笔触沿关键词的下半部分从左向右展开。
动画参数与实现规则：
- 滚动位置在 0.35–1.0 s 从 0→90 px，在 1.6–2.2 s 从 90→180 px，在 3.3–4.4 s 从 180→0，使用三次缓入缓出。
- 两行文案使用 20 px 粗体，分别位于页面纵向 190 px 和 290 px 处，最初隐藏在视口下方。
- 每行顶边越过触发线后，关键词下方的笔触开始展开；触发线位于视口高度的 80%，即 134 px 处。
- 笔触为黄色 #FFE36B，高 11，位于文字下部，从基线上方 8 px 到下方 3 px。宽度在 0.8 s 内从 0 → 关键词宽度，自左向右展开，使用三次缓出，并绘制在文字后方。
- 从视口底部离开的文案行会重置为隐藏状态。
适用场景：适合落地页文案，让关键短语在阅读过程中自然突出。
