请在我的项目中使用「色差（Chromatic aberration）」。
Motion Prompt #111 · 摄影效果、光线与风格

效果含义：高反差边缘出现不同颜色的色边
示例表现：街景分离为红、绿、蓝三层，再以略微不同的大小重新叠加；人物、建筑和路灯边缘出现红色与青色分边，越靠近画面两侧越明显。
动画参数与实现规则：
- 场景 2：街角中，建筑、树木和路灯（x 114、292、494）位于 y 132–162 的道路后方；人物站在左前方，脚底位于 x 176、y 200，身高 124 px。
- 分离：图像分别与红色 #FF0000、绿色 #00FF00、蓝色 #0000FF 相乘，得到三个副本，再在黑色背景上加色合成。
- 围绕画面中心缩放：红色层为 1 + 2s，绿色层为 1 + s，蓝色层为 1，其中 s 从 0 → 0.02。
- 偏移：红蓝两层在左右边缘最终相距约 11 px，在中心相距 0。
- 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合表现旧镜头、VHS 或故障画面的不完美质感。
