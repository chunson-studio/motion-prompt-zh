请在我的项目中使用「范围滑块（Range slider）」。
Motion Prompt #062 · UI 组件

效果含义：双滑块选择最小值与最大值
示例表现：在价格范围滑块上，左把手向右拖，右把手向左拖，选取范围随之缩小，然后两个把手回到原位。
动画参数与实现规则：
- 在 542×191 的卡片上，周期为 4.5 s。轨道位于 x = 54–488、y = 120，高 8；两个把手之间为蓝色。范围为 ¥0–¥10,000。
- 把手为白色，半径 13，带宽 3 px 的蓝色边缘；拖动时半径变为 15，并出现半径 24 的浅蓝色光晕。
- 下限把手在 1.0–1.6 s 从 0.1→0.3，即 ¥1,000→¥3,000，在 3.55–3.9 s 返回。上限把手在 2.1–2.6 s 从 1.0→0.8，即 ¥10,000→¥8,000，在 2.95–3.3 s 返回。全部使用 easeInOutCubic（三次缓入缓出）。
- 每个把手上方有高 28 的数值气泡，拖动时为蓝底白字。右上角用蓝色显示范围“¥1,000 – ¥10,000”，以 ¥100 为步长更新。
- 光标始终位于正在拖动的把手上，按下时间为 1.0、2.1、2.95 和 3.55 s。
适用场景：适合按上下限筛选范围，例如价格、日期或尺寸。
