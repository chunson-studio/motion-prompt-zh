请在我的项目中使用「滚动淡入（Fade-in on scroll）」。
Motion Prompt #074 · 落地页与网页效果

效果含义：元素进入视口时逐渐出现
示例表现：随着页面滚动，标题、卡片和正文进入可视区域时分别上移归位并淡入。
动画参数与实现规则：
- 滚动位置在 0.35–1.0 s 从 0→95 px，在 1.5–2.1 s 从 95→200 px，在 3.2–4.4 s 从 200→0；均使用三次缓入缓出。
- 触发线位于可视区域高度的 85%，即距顶部 143 px。元素顶边越过这条线时触发，体现 Intersection Observer 的工作思路。
- 触发后在 0.7 s 内，不透明度从 0→1，向下偏移从 28 px → 0，使用三次缓出。
- 三个元素分别是页面纵向 172 px 处的标题、206 px 处由三张卡片组成的一行，以及 334 px 处的正文；最初都在视口下方。同一行卡片一起出现。
- 页面向上返回时，元素一旦从视口底部离开，就重置为隐藏状态，下次进入时再次播放。
适用场景：适合长落地页，在读者滚动时逐段呈现内容。
