Motion Prompt #113 · 摄影效果、光线与风格

效果含义：整体明亮、接近白色且阴影很浅
示例表现：景观与人物变为接近白色的浅色调，阴影非常淡，右下角直方图的峰值向右端移动。
动画参数与实现规则：
- 场景 3：左侧为半身像，头部圆心 x 140、y 82，半径 28 px；右侧为山丘、房屋、树木和太阳，太阳位于 x 432、y 54，半径 15 px。
- 颜色：天空 #FAF9F7 → #FFFFFF，山丘 #EAEDF1 → #F5F6F8，人物 #4D5A75 → #B9C0CE，阴影 #33405A → #A6AEBF，太阳 #F5A524 → #FFD889。
- 直方图尺寸为 96×46 px，共 20 根柱；峰值中心从 0.56 → 0.85，分布宽度从 0.2 → 0.09。
- 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合干净、明亮、柔和的产品照与人像。
