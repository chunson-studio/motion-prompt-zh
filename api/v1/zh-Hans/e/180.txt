// 过肩镜头 / Over-the-shoulder
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 12 · 子类别: 角度与构图
// 示例表现: 前景人物的后脑和肩膀占据画面一侧，越过其肩膀可看见另一人；前景虚化，交谈对象清晰。
// 动画参数与实现规则:
//   - 构图：前景人物为灰色，位于左侧 0.62 m、距相机 1.15 m，其后脑和肩膀占据画面左边缘；另一人物为蓝色，位于右侧 0.32 m、距相机 3.1 m，从前景肩膀旁可见。
//   - 对焦：前景肩膀模糊 2.6 px，另一人物保持清晰，取胸部以上的景别。
//   - 相机：高度 1.55 m、偏航角 +0.05 rad；在 0.5–3.4 s 缓慢推进 0 m→0.35 m，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 另一人物的四肢按 0.35·sin(u×5) rad 摆动，仿佛正在说话。
//   - 返回：在 3.4–4.2 s 保持静止，再在最后 0.5 s 交叉淡化回起始状态；右上角读数显示“OTS”。
// 适用场景: 适合交代对话中人物的相对位置，并突出交谈对象的表情。
// 标签: over-the-shoulder, ots, dialogue, conversation, shoulder, two shot, angle, 镜头, 过肩, 对话, 人物, 前景虚化, 构图
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#180
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 12
// 12 オーバーザショルダー: 手前の人物の肩と後頭部を画面の端に入れ、肩越しに相手を撮る。手前はぼけ、相手にピント
CELLS[11] = shot(camCell((k, w, h, p, u) => {
  world(k, w, h, cam({ z: lerp(0, 0.35, p), y: 1.55, yaw: 0.05 }), {
    person: { x: 0.32, z: 3.1, walk: 0.35 * Math.sin(u * 5) }, blurFg: 2.6,
    extra: [[-0.62, 0, 1.15, (kk) => { kk.fillStyle = C.g4; kk.beginPath(); kk.arc(0, 1.63, 0.17, 0, 7); kk.fill(); rr(kk, -0.34, 0.9, 0.68, 0.6, 0.14); kk.fill(); }, true]]
  });
}, p => 'OTS'));
