// 分割光 / Split lighting
// 分类: photo (摄影效果、光线与风格) · element 04 · 子类别: 布光与时段
// 示例表现: 光源从靠近正面的 20° 转至正侧面的 90°；头部阴影从月牙状逐渐扩大到恰好一半，将脸沿中线分成明暗两侧。
// 动画参数与实现规则:
//   - 场景 1：人物半身像位于 y 150 的地平线前方，头部圆心为 x 270、y 78，半径 29 px，不绘制面部或头发。背景变暗，天空颜色为 #E7E5E1。
//   - 光源来自画面左侧，角度从 20° → 90°；右下角显示布光图，右上角读数为“90° · ↑0°”。
//   - 头部：x = 270 + cos(angle)·√(29² − dy²) 右侧为 #33405A 阴影，左侧为 #FFC75A 亮部；到 90° 时，分界变为笔直的中线。
//   - 躯干半宽 56 px：x = 270 + cos(angle)·56 右侧为阴影，左缘保留一条亮部。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合富有戏剧性、紧张感或情绪氛围的人像。
// 标签: split lighting, side light, portrait lighting, half face, dramatic, chiaroscuro, 分割光, 侧光, 明暗分界, 人像, 戏剧性, 布光
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#100
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 04
// スプリットライティング: 光が真横（90°）へ回り、顔の右半分が影に沈む
CELLS[3] = cell((k, u) => {
  const a = env(u), az = lerp(0.35, Math.PI / 2, a);
  stagePortrait(k, pal(BASE, DIM, a));
  const lit = mixc(BASE.person, BASE.lit, a), sh = mixc(BASE.person, BASE.shade, a), W = torsoW(PR);
  bust(k, PX, PY, PR, BASE.person, kk => {
    kk.fillStyle = lit; kk.beginPath(); kk.arc(PX, PY, PR, 0, TAU); kk.fill();
    headShade(kk, PX, PY, PR, az, 1, sh);
    torso(kk, PX, PY, PR, PX - W, PX - Math.cos(az) * 0.4 * W - 0.4 * W, lit);
    torso(kk, PX, PY, PR, PX + Math.cos(az) * W, PX + W, sh);
  });
  plan(k, [[az, a]]);
  hud(k, `${Math.round(az * 180 / Math.PI)}° · ↑0°`);
});
