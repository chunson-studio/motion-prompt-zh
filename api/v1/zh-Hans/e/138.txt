// 百叶窗转场 / Blinds transition
// 分类: motion2 (动态图形（第 2 弹）) · element 18 · 子类别: 转场与强调
// 示例表现: 一排细长条之间的开口逐渐变宽，直到下一个场景完全显露。
// 动画参数与实现规则:
//   - 白昼场景→夜景→白昼，每段 2.35 s。画面分为七条水平条带，每条高度为 208 ÷ 7 ≈ 29.7 px。
//   - 在 0.4–1.65 s，持续 1.25 s，使用二次缓入缓出：所有条带同时从各自上边缘向下揭开下一个场景，开口高度从 0 增至完整条带高度。
//   - 前一个场景保留在下方，两个场景本身均不移动。
// 适用场景: 适合白天与黑夜、前后对比等两个场景的明确切换，也可营造复古感。
// 标签: blinds, venetian-blinds, stripes, transition, wipe, scene-change, 百叶窗, 转场, 条带, 揭示, 日夜, 复古
// 尺寸: 539x208 px · 周期: 4.7 s
// 依赖: kit motion2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/motion2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#138
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 18
// 18 ブラインド（細い帯ごとのすき間がだんだん広がって、次の画面が開く）
CELLS[17] = abCell((k, w, h, u, a, b) => {
  const p = eIOs(P(u, TA - 0.1, TB + 0.15)), N = 7, sh = h / N, S = [scrA, scrB];
  S[a](k, w, h);
  if (p <= 0) return;
  k.save(); k.beginPath(); for (let i = 0; i < N; i++) k.rect(0, i * sh, w, sh * p + (p > 0.999 ? 1 : 0)); k.clip(); S[b](k, w, h); k.restore();
});
