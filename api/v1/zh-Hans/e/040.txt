// 定格 / Freeze frame
// 分类: camera (镜头运动与转场) · element 16 · 子类别: 拍摄方式与时间效果
// 示例表现: 人物跳到最高点的一刻，画面停止；1.4 s 后从同一帧继续播放。
// 动画参数与实现规则:
//   - 相机：完全固定，高度 1.3 m；停止的是影像时间。
//   - 定格：在 1.6 s 停止，在 3.0 s 恢复，持续 1.4 s。影像时间在 0–1.6 s 正常流逝，定格时保持在 1.6 s，之后按 u-1.4 继续。
//   - 主体：前方 7 m 处的人物在影像时间 0.6–2.6 s 沿抛物线跳跃，最高 1.1 m；定格恰好发生在最高点，即进程的 50%。
//   - 九片飘落的树叶在定格时也停止，其落下速度为本组第 13 项慢动作的 1.5×。
//   - 定格标记：宽 5 px 的蓝色边框，以及底部中央的暂停图标；图标为 68×40 px 的白色圆角框上的两条蓝色竖条，在 0.12 s 内淡入或淡出。
//   - 右上角仅在定格期间显示“FREEZE”，没有交叉淡化重置。
// 适用场景: 适合强调决定性瞬间，或暂时停住画面以叠加姓名或说明字幕。
// 标签: freeze frame, still frame, pause, hold, stop motion, highlight, 镜头, 定格, 暂停, 关键帧, 强调, 字幕
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#040
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 16
// 16 フリーズフレーム
CELLS[15] = shot((k, w, h, u) => {
  // 跳躍の頂点で 1.4 秒止める
  const tj = u < 1.6 ? u : u < 3.0 ? 1.6 : u - 1.4;   // 実時間→映像時間
  const q = P(tj, 0.6, 2.6);
  const frozen = u >= 1.6 && u < 3.0;
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(tj, 1.5) });
  if (frozen) {
    const a = Math.min(1, (u - 1.6) / 0.12, (3.0 - u) / 0.12);
    k.save(); k.globalAlpha = a; k.strokeStyle = C.blue; k.lineWidth = 5; k.strokeRect(2.5, 2.5, w - 5, h - 5);
    k.fillStyle = 'rgba(255,255,255,.88)'; rr(k, w / 2 - 34, h - 58, 68, 40, 8); k.fill();
    k.fillStyle = C.blue; k.fillRect(w / 2 - 12, h - 49, 8, 22); k.fillRect(w / 2 + 4, h - 49, 8, 22); k.restore();
  }
  return frozen ? 'FREEZE' : '';
});
