// 蓝调时刻 / Blue hour
// 分类: photo (摄影效果、光线与风格) · element 08 · 子类别: 布光与时段
// 示例表现: 太阳落下后，天空变成两层深蓝色带，窗户与路灯亮起琥珀色灯光，人物成为深蓝色剪影。
// 动画参数与实现规则:
//   - 场景 1：人物半身像位于 y 150 的地平线前方，头部圆心为 x 270、y 78，半径 29 px，不绘制面部或头发。
//   - 太阳半径 18 px，x 为 120；效果达到 70% 前，太阳从 y 40 下沉到 y 190，并在效果的 40% 至 80% 之间淡出。
//   - 颜色：天空顶部为 #2C3B5E，地平线附近为 #4A6191，地面为 #283452，建筑为 #34446B，人物为 #1C2439。
//   - 灯光：每三扇窗中有一扇以及路灯灯泡变为 #FFC75A；灯泡周围有半径 13 px 和 8 px 的平涂光环，颜色 #FFE3A3，不透明度分别为 35% 和 60%。
//   - 右上角时间从 12:00 → 18:35。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合同时保留蓝色天空与暖色灯光的城市或夜景。
// 标签: blue hour, twilight, dusk, night city, cityscape, deep blue sky, 蓝调时刻, 夜景, 城市, 蓝色天空, 灯光, 黄昏
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#104
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 08
// ブルーアワー: 日が沈んだ後、空が深い青になり、窓と街灯の暖かい光が灯る
CELLS[7] = cell((k, u) => {
  const a = env(u);
  const p = pal(BASE, NIGHT, a);
  stagePortrait(k, p, {
    sun: [120, lerp(40, 190, P(a, 0, 0.7)), 18, 1 - P(a, 0.4, 0.8)],
    after: D => { const k2 = D.k; k2.save(); k2.globalAlpha = 0.35 * a; D.circ(413, HZ - 53, 13, BASE.glow); k2.globalAlpha = 0.6 * a; D.circ(413, HZ - 53, 8, BASE.glow); k2.restore(); D.circ(413, HZ - 53, 4, p.bulb); }
  });
  bust(k, PX, PY, PR, p.person);
  hud(k, clock(lerp(720, 1115, a)));
});
