// 环绕镜头 / Orbit (Arc shot)
// 分类: camera (镜头运动与转场) · element 06 · 子类别: 镜头运动
// 示例表现: 相机绕主体沿圆弧移动；人物保持居中，后方树木和建筑横向掠过。
// 动画参数与实现规则:
//   - 相机：以位于前方 9 m 的人物为圆心，沿半径 6 m 的圆弧移动，角度从 -0.95 rad→+0.95 rad，即 -54°→+54°，总计约 109°。
//   - 朝向：始终面对圆心，yaw = -angle；高度 1.7 m，俯仰角固定为 -0.07 rad，约向下 4°。
//   - 时序：0.5–3.6 s，持续 3.1 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物保持不动，脸上的白色圆点随观察角度横向移动；地面用半径 1.3 m 的虚线圆标示中心。
//   - 背景：12 棵树均匀分布在半径 10 m 的圆周上，随着相机环绕，它们从人物背后掠过。
//   - 返回：在 3.6–4.2 s 保持静止，最后 0.5 s 交叉淡化回起始状态；右上角读数显示角度：-54°→+54°。
// 适用场景: 适合立体展示人物或产品，或强调登场与关键时刻。
// 标签: orbit, arc shot, circle, 360, rotate around, revolve, camera move, 镜头, 环绕, 圆弧, 人物, 产品, 立体
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#030
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 06
// 06 オービット: 被写体を中心に円を描いて回り込む
CELLS[5] = shot(camCell((k, w, h, p) => {
  const a = lerp(-0.95, 0.95, p), R = 6, P0 = [0, 0, 9];
  const c = cam({ x: P0[0] + Math.sin(a) * R, z: P0[2] - Math.cos(a) * R, yaw: -a, y: 1.7, pitch: -0.07 });
  world(k, w, h, c, {
    person: { z: 9, face: a }, ring: [0, 9, 10], buildings: true, trees: false,
    after: (kk, cc) => { kk.strokeStyle = C.blueM; kk.lineWidth = 2; kk.setLineDash([5, 5]); kk.beginPath(); for (let i = 0; i <= 48; i++) { const b = i / 48 * Math.PI * 2; const q = proj(cc, Math.sin(b) * 1.3, 0, 9 + Math.cos(b) * 1.3); i ? kk.lineTo(q.x, q.y) : kk.moveTo(q.x, q.y); } kk.stroke(); kk.setLineDash([]); }
  });
}, p => `${Math.round(lerp(-0.95, 0.95, p) * 57.3)}°`.replace(/^(\d)/, '+$1'), 0.5, 3.6));
