// 焦点转移 / Rack focus
// 分类: camera (镜头运动与转场) · element 09 · 子类别: 拍摄方式与时间效果
// 示例表现: 相机不动，焦点从前景花朵移到后方人物，二者的清晰与模糊状态随之交换。
// 动画参数与实现规则:
//   - 相机：位置、朝向和焦距全部固定，高度 1.1 m；仅改变模糊量。
//   - 模糊：前景花朵位于左侧 0.75 m、前方 2 m，模糊量从 0 px→7 px；人物和背景从 6 px→0 px，人物位于右侧 0.9 m、前方 9 m；地面网格使用背景模糊量的 0.6×。
//   - 时序：1.0–2.6 s，持续 1.6 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 对焦标记：蓝色四角框沿直线从花朵移向人物，半宽从 46 px 缩小至 30 px。
//   - 主体：花朵和人物均不移动。
//   - 返回：在 2.6–4.2 s 保持静止，最后 0.5 s 交叉淡化回起始状态；右上角读数显示对焦距离：◎ 2m→◎ 9m。
// 适用场景: 适合无需剪切地将注意力从前景移到背景，或反向转移。
// 标签: rack focus, focus pull, pull focus, depth of field, blur, bokeh, foreground, 镜头, 焦点转移, 对焦, 景深, 虚化, 前后景
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#033
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 09
// 09 ラックフォーカス
CELLS[8] = shot(camCell((k, w, h, p) => {
  world(k, w, h, cam({ y: 1.1 }), {
    person: { x: 0.9, z: 9 }, blurFg: 7 * p, blurBg: 6 * (1 - p),
    extra: [[-0.75, 0, 2.0, (kk, s) => { kk.fillStyle = C.g3; kk.fillRect(-0.025, 0, 0.05, 0.75); kk.fillStyle = C.blueM; for (let i = 0; i < 6; i++) { kk.beginPath(); kk.ellipse(Math.cos(i) * 0.09, 0.8 + Math.sin(i) * 0.09, 0.08, 0.05, i, 0, 7); kk.fill(); } kk.fillStyle = C.blue; kk.beginPath(); kk.arc(0, 0.8, 0.05, 0, 7); kk.fill(); }, true]],
    after: (kk, cc) => {   // ピント位置の枠
      const a = proj(cc, -0.75, 0.8, 2.0), b = proj(cc, 0.9, 0.9, 9);
      const x = lerp(a.x, b.x, p), y = lerp(a.y, b.y, p), r = lerp(46, 30, p);
      kk.strokeStyle = C.blue; kk.lineWidth = 2; kk.beginPath();
      [[-1, -1], [1, -1], [-1, 1], [1, 1]].forEach(([sx, sy]) => { kk.moveTo(x + sx * r, y + sy * r - sy * 9); kk.lineTo(x + sx * r, y + sy * r); kk.lineTo(x + sx * r - sx * 9, y + sy * r); });
      kk.stroke();
    }
  });
}, p => `◎ ${lerp(2, 9, p).toFixed(0)}m`, 1.0, 2.6));
