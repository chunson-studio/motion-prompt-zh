// 暗角 / Vignette
// 分类: photo (摄影效果、光线与风格) · element 16 · 子类别: 镜头与相机效果
// 示例表现: 画面四角平滑变暗，中间的人物和道路仍保持明亮。
// 动画参数与实现规则:
//   - 场景 2：街角中，建筑、树木和路灯（x 114、292、494）位于 y 132–162 的道路后方；人物站在左前方，脚底位于 x 176、y 200，身高 124 px。
//   - 形状为以画面中心为圆心的椭圆，垂直半径 = 水平半径 × 208/539 × 1.35。
//   - 水平半径为 334 px；内侧 45% 的范围保持透明，随后 rgb(32,35,43) 的不透明度从 0% 逐渐升至边缘的 70%。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合将视线集中到主体，或营造旧镜头的观感。
// 标签: vignette, vignetting, dark corners, edge darkening, lens falloff, focus, 暗角, 四角变暗, 主体突出, 镜头, 渐变, 聚焦
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#112
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 16
// 周辺減光（ビネット）: 四隅だけがなだらかに暗くなり、中央の人物に目が集まる
CELLS[15] = cell((k, u) => {
  const a = env(u);
  stageStreet(k, BASE);
  // 楕円の放射グラデーション: 半径の45%までは素通し、外へ向かって 0 → 70% の濃さ
  k.save(); k.translate(CW / 2, CH / 2); k.scale(1, CH / CW * 1.35);
  const g = k.createRadialGradient(0, 0, CW * 0.45 * 0.62, 0, 0, CW * 0.62);
  g.addColorStop(0, 'rgba(32,35,43,0)'); g.addColorStop(1, `rgba(32,35,43,${(0.7 * a).toFixed(3)})`);
  k.fillStyle = g; k.fillRect(-CW, -CW, CW * 2, CW * 2); k.restore();
});
