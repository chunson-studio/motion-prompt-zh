// 定场镜头 / Establishing shot
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 15 · 子类别: 角度与构图
// 示例表现: 以较高机位的广阔视野交代整个城镇；相机缓慢推进，左下角出现地点字幕。
// 动画参数与实现规则:
//   - 相机：使用广角镜头，焦距 220 px，标示为 16mm；高度 4.5 m、俯仰角 -0.06 rad，从 -5 m 缓慢推进至 -2.5 m。
//   - 时序：0.3–4.2 s，持续 3.9 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 场景：八栋城市建筑位于 30 m 远处，一座塔位于右侧 16 m、前方 36 m，另有三朵云和山脉；一个小人物位于左侧 1 m、前方 12 m，提供比例参照。
//   - 地点字幕：在 0.9–1.3 s，一张写有“EXT. CITY – DAY”的白色卡片在左下角上移 8 px 并淡入，随后保持显示；卡片尺寸 158×30 px，左侧有蓝色竖条。
//   - 返回：最后 0.5 s 交叉淡化回起始状态，一次演示为 4.7 s；右上角读数显示“16mm WIDE”。
// 适用场景: 适合场景开头交代地点，或用于地点、时间发生变化的时刻。
// 标签: establishing shot, wide shot, location, opening, scene setting, aerial, framing, 镜头, 定场, 广角, 全景, 地点, 开场
// 尺寸: 539x208 px · 周期: 9.4 s

// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#183

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 15
// 15 エスタブリッシングショット: 広角・高い位置から街全体を見せる引きの画。ゆっくり寄りながら場所の表示が出る
CELLS[14] = shot(camCell((k, w, h, p, u) => {
  const clouds = [[-30, 20, 110, 2.6], [20, 26, 150, 3.2], [60, 17, 95, 2]];
  world(k, w, h, cam({ f: 220, y: 4.5, pitch: -0.06, z: lerp(-5, -2.5, p) }), { city: true, clouds, tower: [16, 36], person: { x: -1, z: 12 } });
  const a = P(u, 0.9, 1.3);   // 場所の表示（左下）
  if (a > 0) { k.save(); k.globalAlpha = a; k.translate(30, h - 52 + (1 - a) * 8); k.fillStyle = 'rgba(255,255,255,.9)'; rr(k, 0, 0, 158, 30, 6); k.fill(); k.fillStyle = C.blue; k.fillRect(0, 0, 4, 30); txt(k, 'EXT. CITY – DAY', 14, 15.5, `600 14px ${MONO}`, C.ink, 'left', 'middle'); k.restore(); }
}, p => `${mm(220)} WIDE`, 0.3, 4.2));
