// 低调 / Low-key
// 分类: photo (摄影效果、光线与风格) · element 18 · 子类别: 色调与后期风格
// 示例表现: 画面大部分沉入黑暗，太阳消失，只有被侧光照亮的半身像右缘保持明亮；直方图峰值移向左端。
// 动画参数与实现规则:
//   - 场景 3：左侧为半身像，头部圆心 x 140、y 82，半径 28 px；右侧为山丘、房屋、树木和太阳，太阳位于 x 432、y 54，半径 15 px。
//   - 颜色：天空 #FAF9F7 → #2B2D33，山丘变为 #313339 与 #36383E，地面变为 #24252A，人物变为 #25272E；太阳与光环改为天空颜色，从画面中消失。
//   - 半身像右侧受光的边缘保留，颜色从 #FFC75A → #FFB547。
//   - 直方图峰值中心从 0.56 → 0.14，分布宽度从 0.2 → 0.08。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合奢华、紧张或神秘的画面氛围。
// 标签: low-key, low key, dark, black background, moody, dramatic, chiaroscuro, 低调, 暗色, 神秘, 侧光, 直方图, 氛围
// 尺寸: 539x208 px · 周期: 5 s

// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#114

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 18
// ローキー: 画面の大半が暗く沈み、横からの光が当たる縁だけが浮かぶ
CELLS[17] = cell((k, u) => {
  const a = env(u);
  const LOW = Object.assign({}, DARK, { sun: DARK.sky, glow: DARK.sky, person: '#25272E', lit: '#FFB547' });
  stageLand(k, pal(BASE, LOW, a));
  histo(k, lerp(0.56, 0.14, a), lerp(0.2, 0.08, a));
});
