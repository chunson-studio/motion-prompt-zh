// 剪影 / Silhouette
// 分类: photo (摄影效果、光线与风格) · element 03 · 子类别: 布光与时段
// 示例表现: 曝光以明亮的傍晚天空为准，人物、建筑、路灯和树木都变成没有细节的纯黑形状，只保留明亮天空。
// 动画参数与实现规则:
//   - 场景 1：人物半身像位于 y 150 的地平线前方，头部圆心为 x 270、y 78，半径 29 px，不绘制面部或头发。
//   - 天空从 #FAF9F7 过渡为顶部的 #FFEDC4，地平线附近 y 92–150 处为 #FFCF73 色带。
//   - 天空以外的物体变为 #2A2D36，远山为 #4A4546，人物为 #22252D。
//   - 太阳半径 20 px，x 为 404，从 y 60 下沉到 y 128，并被山丘遮住一半。
//   - 右上角曝光读数从 ±0.0 EV → −2.0 EV。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合以夕阳或明亮窗户为背景，主要通过轮廓和姿态表达画面。
// 标签: silhouette, backlit, sunset, contre-jour, black shape, underexposed, 剪影, 曝光, 轮廓, 夕阳, 逆光, 暗部
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#099
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 03
// シルエット: 露出を明るい空に合わせると、人物も建物も木も黒い形だけになる
CELLS[2] = cell((k, u) => {
  const a = env(u), INK = '#2A2D36';
  const SILH = mapPal(BASE, () => INK);
  Object.assign(SILH, { sky: '#FFEDC4', sky2: '#FFCF73', far: '#4A4546', sun: BASE.sun, glow: BASE.glow });
  stagePortrait(k, pal(BASE, SILH, a), { sun: [404, lerp(60, 128, a), 20, a] });
  bust(k, PX, PY, PR, mixc(BASE.person, '#22252D', a));
  hud(k, `${(-2 * a).toFixed(1).replace('-0.0', '±0.0')} EV`);
});
