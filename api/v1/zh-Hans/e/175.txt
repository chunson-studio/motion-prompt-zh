// 固定镜头 / Locked-off shot
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 07 · 子类别: 镜头运动
// 示例表现: 相机固定在三脚架上，人物从前方走过，汽车从后方驶过；相机位置丝毫不动。
// 动画参数与实现规则:
//   - 相机：完全固定，高度 1.4 m，朝向正前方，焦距 330 px；只有拍摄对象运动。
//   - 主体：人物在前方 6.5 m 处，以恒定速度从左向右穿过画面，4.7 s 内从 x = -6.2 m 移动到 +6.2 m；四肢摆动角度为 sin(u×7)×0.42 rad。
//   - 一辆灰色汽车在 15 m 远处从右向左驶过，4.7 s 内从 x = +16 m 移动到 -16 m。
//   - 人物和汽车均从画外开始，并在画外结束，因此每 4.7 s 无缝循环。
//   - 左下角有灰色三脚架标记，右上角读数显示“LOCKED”。#040 定格画面会停止影像中的时间；此处时间继续流动，只有相机保持静止。
// 适用场景: 适合通过静止背景突出运动主体、进行定点观察，或作为延时摄影和画面合成的基础。
// 标签: locked-off, locked off, static shot, fixed camera, tripod, static, still camera, 镜头, 固定, 三脚架, 静止机位, 定点, 观察
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#175
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 07
// 07 ロックオフ: 三脚で固定したカメラの前を人物が横切り、奥を車が通る。カメラは1pxも動かない（#040 フリーズフレームは映像が止まる）
CELLS[6] = shot((k, w, h, u) => {
  const q = u / CYC;
  world(k, w, h, cam({ y: 1.4 }), {
    person: { x: lerp(-6.2, 6.2, q), z: 6.5, walk: u * 7 },
    extra: [[lerp(16, -16, q), 0, 15, (kk) => { kk.fillStyle = C.g4; rr(kk, -1.9, 0.35, 3.8, 0.75, 0.25); kk.fill(); rr(kk, -1.1, 0.95, 2.1, 0.62, 0.28); kk.fill(); kk.fillStyle = C.ink; [-1.15, 1.15].forEach(x => { kk.beginPath(); kk.arc(x, 0.34, 0.34, 0, 7); kk.fill(); }); }]],
    after: (kk) => {   // 三脚の印（左下）
      kk.strokeStyle = C.g4; kk.lineWidth = 2.2; kk.lineCap = 'round'; const x = -w / 2 + 38, y = h / 2 - 20;
      kk.beginPath(); kk.moveTo(x, y - 30); kk.lineTo(x - 12, y); kk.moveTo(x, y - 30); kk.lineTo(x + 12, y); kk.moveTo(x, y - 30); kk.lineTo(x, y - 2); kk.stroke();
      kk.fillStyle = C.g4; rr(kk, x - 9, y - 42, 18, 12, 3); kk.fill();
    }
  });
  return 'LOCKED';
});
