// 双色调 / Duotone
// 分类: photo (摄影效果、光线与风格) · element 20 · 子类别: 色调与后期风格
// 示例表现: 同一景观的颜色被替换为两种颜色之间的色阶：暗部为靛蓝，亮部为粉色。
// 动画参数与实现规则:
//   - 场景 3：左侧为半身像，头部圆心 x 140、y 82，半径 28 px；右侧为山丘、房屋、树木和太阳，太阳位于 x 432、y 54，半径 15 px。
//   - 两端颜色：暗端为 #1F2A5C，亮端为 #FF9FB2。
//   - 转换方式：根据每种颜色的亮度 L，计算 t = ((L − 70) / 180)^2.4，再按 t 混合两种颜色，使亮色阶之间的差异更明显。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合用品牌配色统一海报、音乐封面或社交媒体图片。
// 标签: duotone, two-tone, gradient map, color overlay, poster, graphic, 双色调, 靛蓝, 粉色, 品牌配色, 海报, 调色
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#116
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
