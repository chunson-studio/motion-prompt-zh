// 轮廓光 / Rim light
// 分类: photo (摄影效果、光线与风格) · element 02 · 子类别: 布光与时段
// 示例表现: 周围环境变暗，人物左后方和右后方的两盏灯，只在头部与肩膀两侧勾出细亮边；右下角的俯视图标明两盏灯的位置。
// 动画参数与实现规则:
//   - 场景 1：人物半身像位于 y 150 的地平线前方，头部圆心为 x 270、y 78，半径 29 px，不绘制面部或头发。
//   - 背景从明亮场景过渡到暗场景，天空为 #2B2D33，地面为 #24252A；人物颜色从 #4D5A75 → #1F2128。
//   - 亮边：以琥珀色 #FFC75A 绘制两个人物副本，分别向左、右偏移 3.5 px，再向上偏移 2.5 px，放在深色人物后方，形成宽 3.5 px 的边缘。
//   - 右下角布光示意图尺寸为 66×66 px；从上方看，两盏灯位于 ±135°，即左后方和右后方；右上角显示“±135°”。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合将人物或产品从深色背景中分离出来，突出外形。
// 标签: rim light, rim lighting, edge light, backlight, kicker, outline, studio, 轮廓光, 边缘光, 布光, 暗背景, 产品, 人像
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#098
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 02
// リムライト: 周りが暗くなり、斜め後ろ左右の2灯で頭と肩の輪郭だけが細く光る
CELLS[1] = cell((k, u) => {
  const a = env(u);
  stagePortrait(k, pal(BASE, DARK, a));
  k.save(); k.globalAlpha = a; k.fillStyle = BASE.lit;
  for (const dx of [-3.5, 3.5]) { k.save(); k.translate(dx, -2.5); bustPath(k, PX, PY, PR); k.fill(); k.restore(); }
  k.restore();
  bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
  plan(k, [[Math.PI * 0.75, a], [-Math.PI * 0.75, a]]);
  hud(k, '±135°');
});
