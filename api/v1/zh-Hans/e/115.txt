// 黑白 / Black and white
// 分类: photo (摄影效果、光线与风格) · element 19 · 子类别: 色调与后期风格
// 示例表现: 同一景观的色彩逐渐褪去，太阳与人物受光处变为灰色，形状只通过亮度差异呈现。
// 动画参数与实现规则:
//   - 场景 3：左侧为半身像，头部圆心 x 140、y 82，半径 28 px；右侧为山丘、房屋、树木和太阳，太阳位于 x 432、y 54，半径 15 px。
//   - 转换方式：每种颜色按亮度公式 0.2126R + 0.7152G + 0.0722B 转为灰度，再以 140 为中心将对比度乘以 1.25。
//   - 例如人物颜色 #4D5A75 变为约 #4D4D4D，太阳颜色 #F5A524 变为约 #B5B5B5。
//   - 时序：效果在 0.4 s 至 1.4 s 进入，保持到 4.0 s，并在 4.8 s 前完全消失；单次周期 = 5 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合营造经典持久的观感，或突出形状、光线与表情的场景。
// 标签: black and white, monochrome, b&w, grayscale, desaturated, classic, 黑白, 灰度, 亮度, 经典, 对比度, 去色
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#115
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
