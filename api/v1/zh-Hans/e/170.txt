// 横滚镜头 / Barrel roll
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 02 · 子类别: 镜头运动
// 示例表现: 相机绕镜头轴完整翻滚一周，地平线随之旋转一圈并恢复水平。
// 动画参数与实现规则:
//   - 相机：位置固定，高度 1.5 m；仅改变横滚角，从 0→2π rad，即 360°，整幅画面围绕画面中心旋转。
//   - 时序：0.5–3.6 s，持续 3.1 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物静立在前方 7 m 处；地平线、建筑和人物都以相同角度旋转，旋转时画面四角露出白色。
//   - 保持：3.6–4.2 s。旋转完整一周后，画面与初始状态相同，因此最后 0.5 s 的交叉淡化不可见，一次演示为 4.7 s。
//   - 右上角读数显示角度：↻ 0°→↻ 360°。
// 适用场景: 适合需要动感的航拍或无人机画面，也可表现眩晕和混乱。
// 标签: barrel roll, roll, 360, rotate, spin, aerial, camera move, 镜头, 横滚, 旋转, 航拍, 眩晕, 动感
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#170
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 02
// 02 バレルロール: レンズの軸（画面の中央）でカメラを1回転
CELLS[1] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ roll: p * Math.PI * 2 }), { person: { z: 7 } }),
  p => `↻ ${Math.round(p * 360)}°`, 0.5, 3.6));
