// 滑动变焦 / Dolly zoom (Vertigo)
// 分类: camera (镜头运动与转场) · element 08 · 子类别: 镜头运动
// 示例表现: 相机向后拉远，同时按相同比例变焦推近；人物尺寸不变，只有背景向其逼近。
// 动画参数与实现规则:
//   - 相机：人物位于前方 8 m，相机与其距离 d 从 3.2 m→8 m，即后拉 4.8 m；相机高度 1.3 m。
//   - 焦距：f = 330 × d/8 px，即从 132 px→330 px，标示为 10mm→24mm，使距离 ÷ 焦距保持恒定。
//   - 时序：0.5–3.4 s，持续 2.9 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物不动，在画面中的高度不变；头部高度 1.8 m 及脚底位置处绘制宽 160 px 的蓝色虚线，说明尺寸保持恒定。
//   - 背景：48 m 远处的建筑放大约 2.2×，山脉放大约 2.4×，从人物后方逼近；人物前方的地面则缩小。
//   - 返回：在 3.4–4.2 s 保持静止，再在最后 0.5 s 交叉淡化回起始状态，一次演示为 4.7 s。
// 适用场景: 适合表现突然意识到某事的瞬间，或用画面传达不安与震惊。
// 标签: dolly zoom, vertigo, zolly, push pull, background stretch, unease, camera move, 镜头, 滑动变焦, 希区柯克, 推拉, 眩晕, 焦距
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#032
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 08
// 08 ドリーズーム: 人物の大きさは一定、背景だけ伸び縮み
CELLS[7] = shot(camCell((k, w, h, p) => {
  const d = lerp(3.2, 8, p), f = F0 * d / 8 * 1.0;
  const c = cam({ z: 8 - d, f, y: 1.3 });
  world(k, w, h, c, {
    person: { z: 8 }, trees: true,
    after: (kk, cc) => { const top = proj(cc, 0, 1.8, 8).y, bot = proj(cc, 0, 0, 8).y; kk.strokeStyle = C.blue; kk.lineWidth = 1.6; kk.setLineDash([6, 5]); kk.beginPath(); kk.moveTo(-80, top); kk.lineTo(80, top); kk.moveTo(-80, bot); kk.lineTo(80, bot); kk.stroke(); kk.setLineDash([]); }
  });
}, p => mm(F0 * lerp(3.2, 8, p) / 8)));
