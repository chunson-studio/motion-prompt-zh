// 背后跟拍 / Follow shot
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 06 · 子类别: 镜头运动
// 示例表现: 相机沿着人物曲折行走的同一路径，在几米后方跟随；人物背对镜头，始终靠近画面中央。
// 动画参数与实现规则:
//   - 路径：人物沿曲线 x = 1.8·sin(2.2s)、纵深 z = 4 + 9s 行走，参数 s 从 0 到 1，纵深由 4 m 变为 13 m。
//   - 相机：在相同曲线的 s-0.4 位置跟随，约落后 3.6–3.9 m，并始终朝向人物；偏航角 = atan2(person x - camera x, person z - camera z)，高度 1.5 m。
//   - 时序：0.3–4.2 s，持续 3.9 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)；四肢摆动角度为 sin(s×30)×0.42 rad。
//   - 人物背对镜头，始终靠近画面中央；路旁立柱和石头从前景掠过。#029 跟踪镜头则在人物侧面并行移动。
//   - 返回：最后 0.5 s 交叉淡化回起始状态，一次演示为 4.7 s。右上角读数显示与人物的距离：FOLLOW 3.6–3.9m。
// 适用场景: 适合跟随角色一起进入某个场所，或呈现类似游戏的第三人称视角。
// 标签: follow shot, follow, behind, third person, trail, walk, camera move, 镜头, 背后跟拍, 跟随, 第三人称, 路径, 人物
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#174
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 06
// 06 フォローショット: 蛇行して歩く人物の後ろを、少し遅れて同じ道筋でついていく（#029 トラッキングは真横に並ぶ）
CELLS[5] = shot(camCell((k, w, h, p) => {
  const path = s => [1.8 * Math.sin(s * 2.2), 4 + s * 9];
  const [px, pz] = path(p), [cx, cz] = path(p - 0.4);
  world(k, w, h, cam({ x: cx, z: cz, y: 1.5, yaw: Math.atan2(px - cx, pz - cz) }), { person: { x: px, z: pz, walk: p * 30 }, fg: [[-2.4, 7], [2.6, 9.5, 'rock'], [-1.5, 12]] });
}, p => `FOLLOW ${Math.hypot(1.8 * Math.sin(p * 2.2) - 1.8 * Math.sin((p - 0.4) * 2.2), 3.6).toFixed(1)}m`, 0.3, 4.2));
