// 慢动作 / Slow motion
// 分类: camera (镜头运动与转场) · element 13 · 子类别: 拍摄方式与时间效果
// 示例表现: 固定镜头前，人物缓慢跃起再落下，树叶也缓慢飘落，整个动作过程被拉长。
// 动画参数与实现规则:
//   - 相机：完全固定，高度 1.3 m；只有主体运动。
//   - 主体：前方 7 m 处的人物用 3.8 s 完成一次跳跃，时段为 0.5–4.3 s。高度 = 4q(1-q)×1.1 m，沿最高点为 1.1 m 的抛物线运动，q 随时间线性增加。
//   - 腾空时双臂举起；起跳前静立 0.5 s，落地后静立 0.4 s。
//   - 树叶：9 片树叶在 4.7 s 内一边旋转，一边从 3.4 m 高处落到地面，每片相隔周期的 1/9。
//   - 右上角读数显示“120fps ×0.25”，即播放时长拉长为 4×。
//   - 没有停留或交叉淡化重置，每 4.7 s 无缝循环。
// 适用场景: 适合让观众看清短暂的动作或表情，或强调情绪高潮。
// 标签: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump, 镜头, 慢动作, 跳跃, 速度, 细节, 情绪
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#037
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
