// 高角度镜头 / High angle
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 10 · 子类别: 角度与构图
// 示例表现: 相机升高并向下俯拍，人物显得渺小，地面占据画面大部分区域。
// 动画参数与实现规则:
//   - 相机：高度从 1.5 m 升至 4.5 m，同时俯仰角从 0→-0.5 rad，约向下 29°；不向前或向后移动。
//   - 时序：0.6–2.2 s，持续 1.6 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物静立在前方 5 m 处；相机向下俯拍时，人物缩小并移向画面下方，地面网格占据画面大部分区域，地平线从顶部离开。
//   - 保持：在 2.2–4.2 s 保持高角度。#031 升起摇臂镜头会继续升至 9 m；本组第 13 项鸟瞰镜头则以 90° 垂直向下拍摄。
//   - 返回：最后 0.5 s 交叉淡化回平视高度，一次演示为 4.7 s。右上角读数显示角度和高度：↘ 0° · 1.5m→↘ 29° · 4.5m。
// 适用场景: 适合让人物显得脆弱或渺小，或从高处交代场景中的情况。
// 标签: high angle, look down, from above, overhead, vulnerable, angle, 镜头, 高角度, 俯拍, 渺小, 场景, 机位
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#178

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 10
// 10 ハイアングル: カメラを高い位置へ上げ、見下ろす。人物が小さく見える（#031 クレーンアップは上がり続けて全体を見せる）
CELLS[9] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ y: lerp(1.5, 4.5, p), pitch: lerp(0, -0.5, p) }), { person: { z: 5 } }),
  p => `↘ ${Math.round(lerp(0, 0.5, p) * 57.3)}° · ${lerp(1.5, 4.5, p).toFixed(1)}m`, 0.6, 2.2));
