// 交叉溶解 / Cross dissolve
// 分类: camera (镜头运动与转场) · element 20 · 子类别: 转场
// 示例表现: 下一个画面叠在当前画面上，不透明度逐渐升高直至完全替代；中途两幅画面相互透叠。
// 动画参数与实现规则:
//   - 衔接：1.5–3.0 s，持续 1.5 s；后一画面的不透明度从 0→100%。
//   - 缓动：二次缓入缓出，约等于 cubic-bezier(0.45,0,0.55,1)；在 2.25 s 达到 50%。
//   - 前一画面始终以完全不透明的状态保留在下方，后一画面绘制在上方，并非先将前一画面淡出。
//   - 相机：两幅画面中均固定；A 的高度为 1.4 m，B 的高度为 1.6 m、俯仰角 +0.1 rad；主体也不移动。
//   - 0–1.5 s 只显示前一画面，3.0–4.7 s 只显示后一画面。
//   - 每 4.7 s 交替执行 A→B 和 B→A，完整往返为 9.4 s；右上角读数显示“A → B”或“B → A”。
// 适用场景: 适合表现温和的时间流逝或地点变化，也适合进入回忆。
// 标签: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition, 交叉溶解, 叠化, 淡化, 转场, 回忆, 时间
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#044
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。
