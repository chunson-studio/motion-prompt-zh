// 垂直摇镜头 / Tilt
// 分类: camera (镜头运动与转场) · element 02 · 子类别: 镜头运动
// 示例表现: 相机位置不动，镜头从地面人物向上转动，直到看到塔顶。
// 动画参数与实现规则:
//   - 相机：位置固定，高度 1.4 m；仅改变俯仰角，从 -0.06 rad→+0.36 rad，即 -3°→+21°，总计约 24°。
//   - 时序：0.5–3.4 s，持续 2.9 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物静立在前方 7 m；后方 26 m 处是一座高 9.5 m 的塔，天线尖端高 11.8 m。
//   - 画面中所有物体向下滑动：人物从底部离开，塔顶和天线进入画面。
//   - 返回：在 3.4–4.2 s 保持静止，再在最后 0.5 s 交叉淡化回起始状态，一次演示为 4.7 s。
//   - 右上角读数以整数度数显示角度：-3°→+21°。
// 适用场景: 适合展示建筑或人物的高度与规模。
// 标签: tilt, tilt up, pitch, vertical, look up, camera move, 镜头, 垂直摇镜头, 俯仰, 仰拍, 建筑, 运镜
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#026

// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

CELLS[1] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ pitch: lerp(-0.06, 0.36, p), y: 1.4 }), { person: { z: 7 }, tower: [0, 26], buildings: false, sun: [7, 13, 40], sunScale: 0.4 }),
  p => `${Math.round(lerp(-0.06, 0.36, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
