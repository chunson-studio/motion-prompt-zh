// 低角度镜头 / Low angle
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 09 · 子类别: 角度与构图
// 示例表现: 相机降到接近地面的位置并向上仰拍，人物显得高大，建筑也更显巍峨。
// 动画参数与实现规则:
//   - 相机：高度从 1.5 m 降至 0.35 m，同时俯仰角从 0→+0.32 rad，约向上 18°；不向前或向后移动。
//   - 时序：0.6–2.2 s，持续 1.6 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物静立在前方 4.5 m 处；一座高 11.8 m 的塔位于左侧 3 m、前方 22 m。相机仰起时，人物和塔向上延伸，地平线下降。
//   - 保持：在 2.2–4.2 s 保持低角度，留出观察构图本身的时间。
//   - 返回：最后 0.5 s 交叉淡化回平视高度，一次演示为 4.7 s。右上角读数显示角度和高度：↗ 0° · 1.5m→↗ 18° · 0.4m。
// 适用场景: 适合让人物显得强大或高大，或强调建筑的高度。
// 标签: low angle, worm's eye, look up, from below, power, heroic, angle, 镜头, 低角度, 仰拍, 高大, 力量, 建筑
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#177
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 09
// 09 ローアングル: カメラを地面近くに下げ、見上げる。人物が大きく、建物が高く見える
CELLS[8] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ y: lerp(1.5, 0.35, p), pitch: lerp(0, 0.32, p) }), { person: { z: 4.5 }, tower: [-3, 22] }),
  p => `↗ ${Math.round(lerp(0, 0.32, p) * 57.3)}° · ${lerp(1.5, 0.35, p).toFixed(1)}m`, 0.6, 2.2));
