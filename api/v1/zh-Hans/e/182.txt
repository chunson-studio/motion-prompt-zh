// 深焦镜头 / Deep focus
// 分类: camera2 (镜头运动与转场（第 2 弹）) · element 14 · 子类别: 角度与构图
// 示例表现: 从前景花朵到后方人物和建筑，整个画面的各个纵深同时变得清晰。
// 动画参数与实现规则:
//   - 相机：位置、朝向和焦距全部固定，高度 1.1 m；仅改变模糊程度。
//   - 模糊：前景花朵位于左侧 0.75 m、前方 2 m，模糊量从 5 px→0 px；背景包括位于右侧 0.9 m、前方 9 m 的人物，以及建筑和山脉，模糊量从 6 px→0 px。前后景同时变清晰；#033 焦点转移则会让另一侧变模糊。
//   - 时序：0.5–3.4 s，持续 2.9 s，使用三次缓入缓出，约等于 cubic-bezier(0.65,0,0.35,1)。
//   - 对焦标记：花朵和人物上均有蓝色四角框，半宽分别为 46 px 和 30 px；随焦点变清晰，不透明度从 0→1。
//   - 返回：在 3.4–4.2 s 保持静止，再在最后 0.5 s 交叉淡化回起始状态；右上角读数显示光圈 f/1.8→f/16。
// 适用场景: 适合让观众自由观察画面各处，或同时呈现不同纵深上发生的多件事情。
// 标签: deep focus, depth of field, everything sharp, f/16, small aperture, pan focus, focus, 镜头, 深焦, 景深, 清晰, 前后景, 对焦
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#182
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 14
// 14 ディープフォーカス: 手前の花から奥の建物まで、全部に同時にピントが合う（#033 ラックフォーカスは片方ずつ）
CELLS[13] = shot(camCell((k, w, h, p) => {
  world(k, w, h, cam({ y: 1.1 }), {
    person: { x: 0.9, z: 9 }, blurFg: 5 * (1 - p), blurBg: 6 * (1 - p),
    extra: [[-0.75, 0, 2.0, (kk, s) => { kk.fillStyle = C.g3; kk.fillRect(-0.025, 0, 0.05, 0.75); kk.fillStyle = C.blueM; for (let i = 0; i < 6; i++) { kk.beginPath(); kk.ellipse(Math.cos(i) * 0.09, 0.8 + Math.sin(i) * 0.09, 0.08, 0.05, i, 0, 7); kk.fill(); } kk.fillStyle = C.blue; kk.beginPath(); kk.arc(0, 0.8, 0.05, 0, 7); kk.fill(); }, true]],
    after: (kk, cc) => {   // ピントの枠を手前と奥の両方に（合うにつれて濃く）
      kk.globalAlpha = p; kk.strokeStyle = C.blue; kk.lineWidth = 2; kk.beginPath();
      [[proj(cc, -0.75, 0.8, 2.0), 46], [proj(cc, 0.9, 0.9, 9), 30]].forEach(([q, r]) => [[-1, -1], [1, -1], [-1, 1], [1, 1]].forEach(([sx, sy]) => { kk.moveTo(q.x + sx * r, q.y + sy * r - sy * 9); kk.lineTo(q.x + sx * r, q.y + sy * r); kk.lineTo(q.x + sx * r - sx * 9, q.y + sy * r); }));
      kk.stroke(); kk.globalAlpha = 1;
    }
  });
}, p => { const a = lerp(1.8, 16, p); return `f/${a < 10 ? a.toFixed(1) : Math.round(a)}`; }));
