// 分屏 / Split screen
// 分类: motion2 (动态图形（第 2 弹）) · element 24 · 子类别: 转场与强调
// 示例表现: 一个全画幅场景分成两个面板，再分成三个；每个面板内的场景都独立运动。
// 动画参数与实现规则:
//   - 全画幅海景在 0.45–0.95 s 分成两个面板，分隔线从 539 移到 269.5；在 1.4–1.9 s 分成三个面板，分隔线位于 1/3 和 2/3；在 3.75–4.4 s 合并回单一画面。全部使用三次缓入缓出。
//   - 海洋、城市和田野三个场景分别在自己的面板中居中并裁切，内部运动持续进行：海浪与帆船移动，城市窗灯每 4.7 s 切换 8 次，风车每 4.7 s 转两周。
//   - 面板之间使用宽度为 6 的白色分隔线。
// 适用场景: 适合比较、展示同时发生的事件，或并列呈现多个人物与地点，例如前后对比或多组选项。
// 标签: split-screen, multi-screen, panels, side-by-side, comparison, layout, 分屏, 面板, 比较, 并列, 多画面, 转场
// 尺寸: 539x208 px · 周期: 4.7 s
// 依赖: kit motion2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/motion2.js
// 原版动态示例: https://showheyohtaki.github.io/motion-prompt/#144
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用前已清空画布并由 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为单个效果的代码。CELLS、常量和辅助函数在对应的 kit 文件中。原始代码与版权声明按 MIT 许可保留。

// @element 24
// 24 スプリットスクリーン（1枚の画面が2つ、3つに分かれて、別々の場面が同時に動く）
CELLS[23] = (k, w, h, u) => {
  u = snapU(u);
  const s2 = eIO(P(u, 0.45, 0.95)), s3 = eIO(P(u, 1.4, 1.9)), m = eIO(P(u, 3.75, 4.4));
  let b1 = lerp(lerp(w, w / 2, s2), w / 3, s3), b2 = lerp(w, 2 * w / 3, s3);
  b1 = lerp(b1, w, m); b2 = lerp(b2, w, m);
  pnSea(k, 0, b1, h, u, false);
  if (b1 < w - 0.5) pnCity(k, b1, Math.max(b1, b2), h, u, false);
  if (b2 < w - 0.5) pnField(k, b2, w, h, u, false);
  k.fillStyle = '#fff';[b1, b2].forEach(b => { if (b < w - 0.5) k.fillRect(b - 3, 0, 6, h); });
};
